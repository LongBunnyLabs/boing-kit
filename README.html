Boing Kit Docs ​

VitePress source for the Boing Kit documentation site, published to longbunnylabs.github.io/boing-kit.

Prerequisites ​

  • Node.js 18+
  • .NET SDK 6+ and DocFX (dotnet tool install -g docfx)
  • PowerShell 7+ (for build/publish scripts)
  • Git configured with push access to https://github.com/LongBunnyLabs/boing-kit.git

VitePress dependencies are already installed in node_modules/. If you need to reinstall:

cd doc-src
npm install

Dev loop ​

Start a local dev server with hot-reload from doc-src/:

npm run dev

Build only ​

Produces static output in docs/ at the repo root:

powershell
.\doc-src\tools\build-docs.ps1

Publish ​

Builds, mirrors output into a local clone of the public Pages repo, commits, and pushes:

powershell
.\doc-src\tools\publish-docs.ps1

The script clones https://github.com/LongBunnyLabs/boing-kit.git into a sibling directory ../boing-kit-docs-publish on first run. To use a different path, edit $docRepoPath at the top of publish-docs.ps1.

How publishing works ​

The source repo (unity-boing-kit) is private. Only the pre-built HTML/CSS/JS is pushed to the public LongBunnyLabs/boing-kit repo, which has GitHub Pages enabled on its main branch (root). No source code is ever exposed.

unity-boing-kit (private)
  Boing Kit/Assets/Boing Kit/Script/  <- C# source (DocFX reads this)
  docfx.json                          <- DocFX config
  doc-src/                            <- VitePress source (guide)
  doc-src/.docfx-api/                 <- DocFX intermediate YAML (gitignored)
  docs/                               <- full build output (gitignored)
    api/                              <- DocFX HTML
    guide/, index.html ...            <- VitePress HTML

boing-kit-docs-publish (public, Pages repo)
  api/           <- mirrored from docs/api/
  guide/         <- mirrored from docs/guide/
  index.html     <- mirrored from docs/index.html
  ...
