Boing Behavior ​

Add the Boing Behavior component to make an object react bouncily to changes in its own position and rotation.

Any change to the object's transform during Update is picked up by the component and turned into a bouncy effect during LateUpdate.

Typical Use ​

Attach BoingBehavior to an object you intend to move directly — for example, one that follows the mouse cursor. The object will lag behind the cursor as if connected to it by a spring, then settle back when the cursor stops.

The same applies to any script-driven motion: teleports, tween targets, AI movement, etc. As long as the transform is updated during Update, the spring response shows up automatically.

Avoiding Sudden Jumps After Teleports ​

When you intentionally snap an object to a new position or rotation, call BoingBehavior.HandleTeleport() immediately afterward. This resets the spring's internal state so the next LateUpdate doesn't interpret the teleport as a high-velocity displacement and overshoot wildly.

Optional Effects ​

  • Scale effects — off by default; can be enabled in the Inspector to make scale changes also produce a bouncy response.
  • Axis locks — translational and rotational effects can be locked along specific axes in either global or local space.

See the API reference for the full property list, or hover over fields in the Inspector for tooltips.
